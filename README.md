# 比手畫腳・家庭同樂版

一款給 6–12 歲兒童與家庭玩的繁體中文 PWA。內含原有 8 大類 128 張字卡，以及獨立的「綜合擴充題」200 張，合計 328 張不重複題目；也能選擇「不分類別（綜合）」從全部題目隨機出題。遊戲預設為無限時間，支援手機與 iPad 的直向、橫向操作，安裝後可離線遊玩。

字卡使用本機 OpenMoji 彩色圖片，載入失敗時會自動顯示系統 Emoji；素材來源與授權請見 [`CREDITS.md`](CREDITS.md)。

## 電腦雙擊測試

1. 雙擊 `啟動遊戲伺服器.bat`。
2. 視窗會顯示遊戲網址，並自動開啟瀏覽器。
3. 測試期間請保留黑色伺服器視窗；結束時按 `Ctrl+C` 或關閉視窗。

若 Windows 詢問網路存取權限，請允許「私人網路」。電腦需已安裝 Python 3；批次檔會自動嘗試 `py -3` 與 `python`。

> 不建議直接雙擊 `index.html`。瀏覽器只有透過 `http://` 或 `https://` 開啟時，才能正常註冊離線功能。

## 手機或 iPad 同 Wi-Fi 開啟

1. 先讓電腦和手機／iPad 連上同一個 Wi-Fi。
2. 在電腦雙擊 `啟動遊戲伺服器.bat`。
3. 找到視窗中的「同 Wi-Fi 裝置」網址，例如 `http://192.168.1.23:8088`。
4. 在手機 Safari 或 Chrome 輸入完整網址。
5. iPhone／iPad 可在 Safari 按「分享」→「加入主畫面」；Android Chrome 可從選單選「安裝應用程式」或「加到主畫面」。

若手機無法連線，請確認兩台裝置仍在同一 Wi-Fi，且 Windows 防火牆已允許 Python 使用私人網路。部分訪客 Wi-Fi 會隔離裝置，這種網路無法互相連線。

## 驗證

在專案資料夾執行：

```powershell
py -3 tests/verify.py
```

驗證會檢查必要檔案、PNG 尺寸、manifest、離線快取、字卡數量與唯一性，以及是否殘留未完成標記。

若新增或修改字卡的 Emoji，請先執行 `python scripts/sync_openmoji.py`，同步本機圖片及離線素材清單，再執行完整驗證。
